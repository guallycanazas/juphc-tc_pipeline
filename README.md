# Customer Accounts Microservice

![Build Status](https://img.shields.io/badge/build-passing-brightgreen)

Customer Accounts is the IBM DevOps Capstone microservice used to manage customer account records through a RESTful API. The project demonstrates agile planning, test-driven REST development, continuous integration, security hardening, containerization, Kubernetes deployment, and continuous delivery automation.

## Project name

Customer Accounts Microservice

## Main capabilities

- Create a customer account.
- List all customer accounts.
- Read one customer account by ID.
- Update account fields.
- Delete an account.
- Run automated tests with nosetests and coverage.
- Validate code quality with Flake8 and Pylint.
- Build a Docker image and deploy it to Kubernetes.
- Automate deployment with a Tekton pipeline.
